# Fleet janitor incidents

One dated line per cause that is a pattern: what happened, what changed, a link.

- 13 November 2026: in 5 daily runs (9 to 13 November) the janitor never swept a session or pruned a worktree. On 9, 10 and 11 November the first Bash call waited on a permission prompt in an unattended run. It was interrupted 49 minutes later. On 12 November one repository answered HTTP 500, and the prompt said to stop on any unreadable repository. On 13 November the run printed 80 lines of `fleet-status` (4 of 21 repositories). Version 3's propose-only mode ran steps 1 to 3 only, so step 4 was never reached. Version 4 (plan row 1.5) changed 5 things. It retries, then goes on past an unreadable repository. It runs `fleet-status-local.sh --save` and reads the whole file. Every step runs in a dry run. A file that Desk writes sets the mode. `scripts/janitor-prune.mjs` does the git work, with its guards under test.
- 18 November 2026: a read of 5 dry runs (14 to 18 November) found 2 defects before the first live run. Step 4 took a session for done from its folder's branch: on 18 November it marked a session in the shared main clone `merged` while its own pull request was open, and on 16 November it would have archived a session whose pull request, in another repository, was open. Step 5 would have deleted an origin branch without asking whether an open pull request used it as its head or its base, and deleting a base closes those pull requests. Now `janitor-prune.mjs sessions` gives each session an `own` verdict from its own `prNumber` and `prState`, and step 4 reads that first. The prune reads a repository's open pull requests once before any origin delete, and deletes nothing when that read fails. Both are under test in `test/janitorPrune.test.mjs`.
- 20 November 2026: `~/.desk/pr-cost.jsonl` stopped growing on 16 November (208 rows: 207 from the 14 November backfill, 1 from a janitor run). Cost recording was step 4.7 of the janitor prompt, which runs only for a session it is about to archive, and the janitor has run dry since 14 November, so it archives none. Added `pr-cost.mjs sweep`: it records every PR in ship-bot's log as merged and not yet in the ledger, from one transcript scan, with no GitHub call. The weekly scorecard job runs it. Step 4.7 stays for closed-unmerged PRs. Plan row 1.53.

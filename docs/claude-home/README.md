# claude-home

The reviewed record of `~/.claude` on gorfpael. `~/.claude` isn't a repository. A change to a file there goes in a pull request here that updates its copy.

- The live files are in `~/.claude`. These are copies.
- Only files a pull request changed are here. A file not listed hasn't been changed through one yet.
- `settings.json` has no secrets: permissions, hooks, plugins, one env flag.
- The rules drift guard (plan row 5.4, PR 144) will scan these files once it lands.

Not mirrored: history, sessions, projects, memory, caches.

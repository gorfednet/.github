## Fleet-wide finding: the Claude review job fails on every Dependabot pull request

Every Dependabot PR shows `review / review: FAILURE` at the `Review` step (for example bindercurve.com run 42341492056). GitHub withholds repository secrets from workflows triggered by Dependabot, so the reviewer cannot authenticate. The ship-bot session owns the fix in `gorfednet.github/.github/workflows/claude-review.yml`: skip the job on `pull_request` when the actor is `dependabot[bot]`, and let a `claude review` comment (an `issue_comment` by a member, which does get secrets) run it. Until then no Dependabot PR can pass the review gate.
